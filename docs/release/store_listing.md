## 完整說明 (Full Description)

```text
【專為國立臺東大學（NTTU）師生打造的次世代智慧校園助理】

NttuEclass 是一款極致輕量、無廣告、離線優先且具備高度隱私保護的臺東大學網路學園行動應用程式。告別繁瑣的手機瀏覽器網頁縮放，隨時掌握課表、課程最新公告與重要作業截止日期！

✨ 核心功能特色：

1. 📅 智慧動態課表 (Timetable)
• 完整支援臺東大學 1~9 節及 10(A) ~ 14(E) 夜間與彈性節次。
• 直覺美觀的課堂色塊設計，點擊可即時查看教室位置、授課教授與課程學分。
• 課前 15 分鐘智慧精準推播提醒，告別跑錯教室與遲到困擾。

2. 📢 課程公告與更新通知 (Announcements)
• 本學期已選課程公告自動排程整理，重要校園訊息不漏接。
• 支援離線快取，在地下室或無網路訊號環境下依然能流暢查閱歷史公告。

3. 📝 作業測驗倒數與提醒 (Assignments & Quizzes)
• 自動聚合各科作業未繳交清單與測驗時限。
• 依繳交期限智慧標記急迫度（倒數 3 日、倒數 1 日），協助妥善規劃課業時程。

4. 🪪 NttuEPass 校園數位通行證
• NttuPass (校園一維條碼)：自動將學號轉換為標準 Code 128 條碼，支援圖書館借書掃描與門禁感應。
• NttuDataPass (ECC-256 特權加密二維條碼)：採用高規格 NIST P-256 (secp256r1) + AES-256-GCM 認證加密，提供安全動態驗證。
• 進入通行證頁面自動調高螢幕亮度，刷卡借書一次過關。

5. 🌗 雙主題極致視覺與 OLED 純黑體驗
• 碧海藍主題：萃取臺東大學網路學園標誌性的太平洋蔚藍，清新舒適。
• 純淨黑白灰階主題：專為 OLED 螢幕量身打造之極黑主題（#121212），杜絕彩色雜染，極致護眼又省電。

6. 🔒 嚴格資安防護與防鎖定機制
• 專利級智慧密碼防護：嚴密監控台東大學學園 5 次密碼錯誤鎖定機制，防止帳號遭鎖定 30 分鐘。
• 100% 本地端安全加密：所有帳號憑證僅儲存於 Android KeyStore AES-256 加密容器中，絕不上傳任何第三方伺服器。
```
